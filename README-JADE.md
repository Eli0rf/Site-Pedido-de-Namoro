# 💖 Site de Pedido de Namoro Personalizado para Jade

Site personalizado para pedir Jade em namoro, com painel administrativo secreto para personalização completa!

## ✨ Funcionalidades

- **Pergunta interativa** - Botão "Sim" e botão "Não" que foge
- **Painel Admin Secreto** - Personalize tudo antes de enviar
- **Upload de fotos** - Adicione fotos suas e da Jade
- **Vídeos** - Adicione vídeos especiais ou do YouTube
- **Textos personalizados** - Mude todos os textos
- **Cores customizadas** - Escolha as cores do site
- **Galeria de fotos** - Adicione múltiplas fotos
- **Salvamento automático** - Tudo salvo no navegador

## 🚀 Como Usar

### 1. Abra o arquivo `jade.html` no navegador

### 2. Abra o Painel Admin
Pressione **Ctrl + Shift + A** (ou **Cmd + Shift + A** no Mac)

### 3. Personalize para Jade
- **Aba Textos**: Mude o título, subtítulo, mensagens
- **Aba Fotos**: Adicione foto principal, fotos de vocês, imagem de fundo
- **Aba Vídeos**: Adicione um vídeo especial ou link do YouTube
- **Aba Cores**: Personalize as cores do site

### 4. Salve as Alterações
Clique no botão **💾 Salvar Alterações**

### 5. Envie para Jade
Hospede o site e envie a URL para ela! 

## 🌐 Como Hospedar (Enviar via URL)

### Opção 1: GitHub Pages (Recomendado)
1. Crie uma conta no GitHub
2. Crie um novo repositório
3. Faça upload dos arquivos: `jade.html`, `jade.css`, `jade.js`
4. Ative GitHub Pages nas configurações
5. Sua URL será: `https://seu-usuario.github.io/nome-do-repositorio/jade.html`

### Opção 2: Netlify (Mais Fácil)
1. Acesse [netlify.com](https://netlify.com)
2. Arraste a pasta com os arquivos
3. Pronto! Você terá uma URL instantânea

### Opção 3: Vercel
1. Acesse [vercel.com](https://vercel.com)
2. Importe os arquivos
3. Deploy automático com URL

## 📁 Arquivos do Projeto

- `jade.html` - Página principal
- `jade.css` - Estilos personalizados
- `jade.js` - Funcionalidades e painel admin
- `index.html` - Site original (backup)
- `style.css` - CSS original (backup)
- `script.js` - JS original (backup)

## 🎨 Dicas de Personalização

1. **Foto Principal**: Use uma foto linda da Jade ou de vocês juntos
2. **Título**: Seja criativo! Ex: "Jade, você aceita namorar comigo?"
3. **Subtítulo**: Adicione algo fofo sobre ela
4. **Mensagem de Resposta**: Prepare uma mensagem romântica para quando ela clicar em "Sim"
5. **Galeria**: Adicione várias fotos de momentos especiais
6. **Vídeo**: Grave um vídeo especial ou escolha uma música no YouTube
7. **Cores**: Use as cores favoritas dela

## 💾 Exportar/Importar Configuração

- **Exportar**: Salve suas configurações em um arquivo JSON
- **Importar**: Carregue configurações salvas anteriormente

## 🔒 Segurança

O painel admin só é acessível por você através do atalho secreto (Ctrl+Shift+A). Jade não verá o painel quando abrir o site!
