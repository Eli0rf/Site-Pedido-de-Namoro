# 🚀 GUIA RÁPIDO - Como Hospedar e Enviar para Jade

## Método 1: Netlify Drop (MAIS FÁCIL - 2 minutos!)

### Passo a Passo:
1. Acesse: https://app.netlify.com/drop
2. Arraste os 3 arquivos para a área indicada:
   - `jade.html`
   - `jade.css`
   - `jade.js`
3. Aguarde o upload (alguns segundos)
4. **PRONTO!** Você receberá uma URL tipo: `https://nome-aleatorio.netlify.app/jade.html`
5. Personalize no painel admin (Ctrl+Shift+A) ANTES de enviar para Jade
6. Copie e envie a URL para ela! 💕

**Vantagens:**
- Não precisa criar conta
- URL funcionando em 2 minutos
- Gratuito para sempre
- HTTPS automático

---

## Método 2: GitHub Pages (Recomendado para controle)

### Passo a Passo:
1. Crie conta no GitHub (se não tiver)
2. Crie um novo repositório público
3. Nome sugerido: `pedido-jade` (ou o que preferir)
4. Faça upload dos 3 arquivos:
   - `jade.html`
   - `jade.css`
   - `jade.js`
5. Vá em Settings → Pages
6. Em "Source", selecione "main" branch
7. Clique em Save
8. Aguarde 2-3 minutos
9. Sua URL será: `https://seu-usuario.github.io/pedido-jade/jade.html`

**Vantagens:**
- Controle total
- Pode editar depois
- Gratuito
- Profissional

---

## Método 3: Vercel (Alternativa rápida)

### Passo a Passo:
1. Acesse: https://vercel.com
2. Crie conta gratuita (pode usar GitHub)
3. Clique em "Add New" → "Project"
4. Faça upload dos arquivos
5. Deploy automático
6. URL pronta: `https://seu-projeto.vercel.app/jade.html`

## ⚠️ IMPORTANTE - Personalize ANTES de enviar!

### Antes de enviar a URL para Jade:

1. **Abra o site localmente** (clique duplo em `jade.html`)
2. **Pressione Ctrl+Shift+A** (ou Cmd+Shift+A no Mac)
3. **Personalize tudo**:
   - Adicione fotos de vocês
   - Escreva mensagens românticas
   - Escolha cores especiais
   - Adicione vídeo ou música
4. **Clique em "Salvar Alterações"**
5. **Feche o navegador**
6. **Hospede os arquivos** (método acima)
7. **Abra a URL hospedada**
8. **Pressione Ctrl+Shift+A novamente** e personalize lá também
9. **Salve**
10. **Agora sim, envie para Jade!** 💖

## 🎯 URL Personalizada (Opcional)

Se quiser uma URL mais bonita tipo `jade.seudominio.com`:

1. Compre um domínio (R$ 40/ano na Registro.br ou hostinger.com)
2. Configure o DNS apontando para o Netlify/Vercel/GitHub Pages
3. Pronto! URL personalizada

Mas isso é opcional, a URL gratuita funciona perfeitamente!

## 💡 Dicas Extras

### Para testar localmente:
- Clique duplo no arquivo `jade.html`
- Ou use Live Server no VS Code
- Pressione Ctrl+Shift+A para abrir o painel admin

### Personalização local vs hospedado:
⚠️ **ATENÇÃO**: O localStorage é separado!
- Se você personalizar localmente e depois hospedar, terá que personalizar novamente na URL hospedada
- Ou use a função "Exportar Config" localmente e depois "Importar Config" na URL hospedada

### Melhor fluxo:
1. Hospede primeiro (sem personalização)
2. Abra a URL hospedada
3. Personalize direto na URL hospedada (Ctrl+Shift+A)
4. Salve
5. Envie essa URL para Jade

## 📱 Testando antes de enviar

Antes de enviar para Jade, teste:
- ✅ O botão "Não" foge quando passa o mouse?
- ✅ O botão "Sim" mostra a mensagem com corações?
- ✅ As fotos estão aparecendo?
- ✅ O vídeo está funcionando?
- ✅ As cores estão bonitas?
- ✅ Os textos estão corretos?
- ✅ Teste no celular também!

---

## 🆘 Problemas Comuns

**Fotos não aparecem após hospedar:**
- As fotos são salvas em Base64 no localStorage
- Certifique-se de personalizar na URL hospedada, não localmente

**Painel admin não abre:**
- Pressione Ctrl+Shift+A (Windows/Linux)
- Ou Cmd+Shift+A (Mac)
- Certifique-se que está na página certa

**URL não funciona:**
- Aguarde alguns minutos após hospedar
- Verifique se adicionou `/jade.html` no final da URL
- Teste em navegação anônima
